TECHNICAL REPORT

Constructing Language Judgments

Rubric Distillation and Evidence-Grounded Reasoning

Architecture for tracing rubric-based judgments from source evidence to criterion scores, with explicit verification and teacher review.

Archived technical report · Not peer-reviewed.

Read on Zenodo ↗Report PDF ↗
Full abstract and credit-assignment figure

Gnomon constructs language judgments through rubric distillation, evidence-grounded reasoning and constrained aggregation. A versioned rubric compiler supplies shared item definitions to an execution harness that elicits observations, verifies source spans and accounts for relation-level credit before constructing criterion scores. Structured extraction targets and candidate-bound critique-and-repair examples connect this inference architecture to verifier-filtered supervision.

Engineering references

Eight tools for evaluating AI systems, checking agent behavior and measuring delivery.

failclosed-eval

An offline validation layer that checks evaluation inputs before model runs, refusing defective data and tracking per-criterion denominators with content hashes.

View repository ↗

policy-deck

A dependency-free command-text classifier that measures guardrail mistakes through an executable error budget.

View repository ↗

mcp-trajectory-judge

Checks what a tool trajectory did, not merely what its final message claims, by replaying synthetic MCP-style trajectories in a deterministic sandbox.

View repository ↗

rollout-sentinel

Inspects the work behind an agent's completion claim by analyzing rollouts against unsafe-behavior rules and completion checks.

View repository ↗

release-gate

A deterministic decision gate for rubric-score fixtures that prevents high averages from silently overriding release policy.

View repository ↗

model-error-translator

A deterministic admission and failure-translation prototype: stops invalid requests before dispatch, explains failures without inventing certainty.

View repository ↗

real-token-meter

Measures training throughput and cost from non-padding tokens, excluding padded sequences for accurate performance comparisons.

View repository ↗

relay-gate

A safety gate for coding-agent trajectories: six deterministic rules run offline before escalating ambiguous cases to a model.
